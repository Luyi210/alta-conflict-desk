# 新版核心流程演示顺序（待录制）

目标版本 v0.9.1。按用户要求暂缓视频；本文件是制作大纲，不是录制记录。早期说明见 [历史文档](history/DEMO-HISTORY.md)。

建议 4—6 分钟，围绕一宗虚构融资事项讲清客户边界和保密义务的核实。

| 顺序 | 展示内容 | 要证明的事情 |
| --- | --- | --- |
| 1 | 案件工作台与大屏 | 收案审查场景与已有记录 |
| 2 | 连接 GLEIF、台账和材料；查看工具 | 真实 MCP 发现、权限与连接状态 |
| 3 | 新建事项、搜索确认企业 | 名称／LEI／辖区与多主体范围 |
| 4 | AI 核查、调用记录与返回 | 模型实际发起工具调用；规则和模型次数分开 |
| 5 | PDF 授权及 AI 审查 | 原文、页码、版本与调用凭证 |
| 6 | 核对引用、编辑草稿、采用到问题 | 律师主导，建议可用且可复核 |
| 7 | 材料变化、人工意见与 Word 导出 | 旧依据保留及交接闭环 |

录制前确认模型可用与连接器连通，使用虚构台账和 PDF，页面不露密钥。等待和失败可保留；若压缩长等待，标注时间压缩，不把旧结果展示成新运行。
