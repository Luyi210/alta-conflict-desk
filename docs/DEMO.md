# 现场讲解顺序 · v0.9.1

当前按用户要求暂缓录制连续视频；本文件也可用于现场操作讲解。早期版本说明见 [历史文档](history/DEMO-HISTORY.md)。

建议 4—6 分钟，围绕一宗虚构融资事项讲清客户边界和保密义务的核实。

| 顺序 | 操作 | 律师要核对什么 |
| --- | --- | --- |
| 1 | 打开案件工作台与审查总览 | 哪些事项仍在审查，哪些问题待处理 |
| 2 | 连接 GLEIF、台账与材料，查看工具和权限 | 各来源能查什么、当前是否允许调用 |
| 3 | 新建融资事项，搜索并确认企业 | 法律名称、LEI、辖区和各方角色 |
| 4 | 执行主体核查，展开调用记录 | 命中依据、来源缺口及模型与规则调用的区别 |
| 5 | 导入 PDF 并授权指定版本 | 模型读取了哪份文件、哪一页，引用是否对应原文 |
| 6 | 编辑建议并采用为审查问题 | 律师如何修改措辞、分配待办和保留依据 |
| 7 | 上传材料新版、记录意见、导出 Word | 旧意见怎样受版本变化影响，交接文件包含什么 |

录制前确认模型可用与连接器连通，使用虚构台账和 PDF，页面不露密钥。等待和失败可保留；若压缩长等待，标注时间压缩，不把旧结果展示成新运行。
