## 本次可复验命令

```bash
npm ci
npm test
npm run build
npm run test:case-live
npm run test:tools-live
npm run dev
```

实时脚本使用隔离临时数据库，不改日常演示记录。外部网络失败应明确报错；没有静默假数据降级。原 v0.1 `test:live` 与视频继续保留作历史证据。
